# RoastMaster 3000

A simple Python command-line application to generate lighthearted roasts for a given name.

## Features

*   Enter a name and get a randomly selected roast.
*   A curated list of generic, SFW (Safe For Work) jokes.
*   Option to generate multiple roasts in one session.

## How to Run

1.  Ensure you have Python 3 installed on your system.
2.  Save the `roast_app.py` script to a directory on your computer.
3.  Open a terminal or command prompt.
4.  Navigate to the directory where you saved `roast_app.py`.
5.  Run the script using the following command:

    ```bash
    python roast_app.py
    ```

6.  Follow the on-screen prompts to enter a name and generate roasts.

## Disclaimer

This application is intended for fun and should be used responsibly. The "roasts" are meant to be silly and not genuinely offensive.
